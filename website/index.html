A FEW LITTLE DETAILS

Glad you asked.

Here’s what to know before
you bring your team along.

Is this really free and open source?+

Yes. The code is available under the MIT license. You can use, modify, and self-host it, including for commercial teams. Your hosting and Supabase usage may have their own costs.

Is the public demo connected to a real team?+

No. The demo uses fictional people and browser-local sample data. It does not connect to our Supabase project. Its QR, shift, and GPS behavior is simulated; the connected application verifies these on the server.

Can I run the entire app on GitHub Pages?+

GitHub Pages hosts this project website and the static demo. A live workspace also needs the Express backend and your own Supabase project. The setup guide covers local development and deployment.

What if someone forgets to check in?+

Team members can request a correction to an existing attendance record. An administrator reviews the reason and proposed time. Approved changes keep the original time and an audit history.

Will it work for my kind of team?+

It supports location-based teams with administrators, employees, workplaces, and recurring shifts, including overnight schedules. It does not currently include leave management, payroll calculations, or device attestation.
