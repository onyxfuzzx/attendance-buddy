# Our community

Attendance Buddy is built for people, and that includes the people building it.

Be respectful, welcome questions, and give constructive feedback. Discuss code and ideas without personal attacks. Respect others' privacy and avoid sharing personal information, credentials, or workplace attendance records.

Harassment, discrimination, threats, and deliberately disruptive behavior are not welcome. Maintainers may edit or remove inappropriate content and restrict participation when necessary to keep the project useful and welcoming.

These expectations apply to issues, pull requests, discussions, reviews, and other project spaces. Raise moderation concerns with repository maintainers through an appropriate GitHub channel, without republishing private information.
